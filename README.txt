클릭다운 (초보자용 GUI 다운로더) - TXT 안내

[1] ZIP 다운로드(깃허브)
1) 저장소 메인으로 이동: https://github.com/1l1l1l111/1
2) 상단에서 Pull requests 화면이 아니라 Code(코드) 화면으로 이동
3) 초록색 Code 버튼 클릭
4) Download ZIP 클릭

[2] 파이썬 없이 EXE 받는 방법 (추천)
1) 저장소 상단 Actions 탭 클릭
2) "윈도우 EXE 빌드" 워크플로 클릭
3) Run workflow 버튼 클릭
4) 완료 후 실행 결과 화면 하단 Artifacts에서
   "클릭다운-windows-exe" 다운로드
5) ZIP 풀면 "클릭다운.exe" 실행 가능

[3] 프로그램 실행 파일
- 클릭다운.exe (파이썬 설치 없이 실행)

[4] 프로그램 사용 순서
1) 링크(영상/재생목록) 붙여넣기
2) 저장 폴더 선택
3) video 또는 audio 선택
4) 다운로드 시작

[5] 안될 때
- 깃허브 화면에서 ZIP/EXE가 안 보이면 PR 화면일 가능성이 큼
- 반드시 저장소 메인(Code 파일 목록)으로 이동해서 진행
