# 클릭다운 (초보자용 GUI 다운로더)

코딩 몰라도 됩니다. **파일 하나만 더블클릭**해서 실행/EXE 생성/설치파일 생성까지 할 수 있게 정리했습니다.

## 깃허브에서 어렵지 않게 보는 법
- 영어 버튼/용어가 헷갈리면 `깃허브_초보_가이드.md`를 먼저 보세요.
- 앞으로 이 프로젝트 문서는 **한글 우선**으로 유지합니다.

## 파일 구성 (핵심만 남김)
- `app.py` : 실제 프로그램
- `requirements.txt` : 필요한 모듈 목록
- `클릭다운_원클릭_센터.bat` : 초보자용 메인 실행 파일 (이것만 누르면 됨)
- `installer.iss` : 설치파일(Setup.exe) 만들 때 내부적으로 사용하는 설정 파일

## 진짜 사용 순서 (초보자 버전)
1. `클릭다운_원클릭_센터.bat` 더블클릭
2. 화면에서 번호 선택
   - `1` = 그냥 바로 실행
   - `2` = EXE 만들고 실행
   - `3` = 설치파일(Setup.exe) 만들기

## 프로그램 사용법
1. 영상/재생목록 링크를 여러 줄로 붙여넣기
2. 저장 폴더 선택
3. `video` 또는 `audio` 선택
4. `다운로드 시작` 클릭

## 안될 때
- Python 오류가 뜨면: https://www.python.org/downloads/ 설치 후 다시 시도
- 설치할 때 꼭 **Add Python to PATH** 체크
- 빌드 실패 시 같은 폴더의 `clickdown_log.txt` 확인
- 설치파일(3번)은 Inno Setup이 필요하며, 없으면 자동 안내 문구가 뜹니다
