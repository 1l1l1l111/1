# 클릭다운 (GUI 영상/음원 다운로더)

코딩을 몰라도 **딸깍 실행**으로 쓰는 걸 목표로 만든 프로그램입니다.

## 기능
- 링크 여러 개를 한 번에 입력해서 다운로드
- 재생목록 링크를 넣으면 자동으로 목록 전체 인식
- 비디오(`video`) / 음원 MP3(`audio`) 선택
- 저장 폴더 직접 선택
- 깔끔한 GUI (밝은 톤, 직관적 레이아웃)

## 실행 방법 (완전 초보자용)
### 1) 진짜 원클릭(EXE 만들고 바로 실행)
1. `원클릭_EXE_만들고_실행.bat` 더블클릭
2. 자동으로 설치/빌드 후 `클릭다운.exe`를 바로 실행

### 1-1) 설치 마법사(Setup.exe)로 배포하고 싶을 때
1. `설치파일_원클릭_생성.bat` 더블클릭
2. 자동으로 `dist/클릭다운_설치파일.exe` 생성
3. 생성된 설치파일을 실행하면 설치 마법사 방식으로 설치 가능
4. 최초 1회는 Inno Setup 설치가 필요할 수 있음 (스크립트가 자동 안내)

### 2) 바로 실행(파이썬으로 실행)
1. `첫실행_설치후실행.bat` 더블클릭
2. 자동으로 필요한 패키지 설치 후 프로그램 실행

### 3) exe만 따로 만들기
1. `exe_빌드.bat` 더블클릭
2. 완료 후 `dist/클릭다운.exe` 생성
3. 이후에는 exe만 실행하면 됨

## 사용법
1. 다운로드할 링크(영상/재생목록)를 여러 줄로 붙여넣기
2. 저장 폴더 선택
3. 형식 `video` 또는 `audio` 선택
4. `다운로드 시작` 클릭

## 주의
- 다운로드 대상 서비스의 이용약관/저작권을 지켜서 사용하세요.
- 일부 사이트는 정책 변경으로 다운로드가 제한될 수 있습니다.


## 꼭 알아두기
- EXE를 "만드는" 과정은 최초 1회 Python 설치가 필요합니다.
- EXE가 한 번 만들어지면, 그 다음부터는 `dist/클릭다운.exe`만 더블클릭해서 사용하면 됩니다.

- 설치 마법사 파일은 `installer.iss`를 사용합니다.
